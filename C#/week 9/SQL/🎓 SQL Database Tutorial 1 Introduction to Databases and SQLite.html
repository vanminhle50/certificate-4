🧩 1. What is a Database?

A database is an organized collection of data. It allows you to store, manage, and retrieve data efficiently.

✅ Key Features:

  • Structured format (tables, rows, columns)

  • Easy to search, filter, and analyze

  • Scalable and secure

🧠 Example:

Think of an Excel spreadsheet:

  • Each sheet is like a table

  • Each row is a record

  • Each column is a field

🔗 2. What is a Relational Database?

A Relational Database connects multiple tables using relationships (usually by keys).

🔄 Key Concepts:

  • Primary Key: Uniquely identifies each record in a table.

  • Foreign Key: Refers to the primary key in another table.

🧠 Excel Activity:

🧾 Orders Table

🧰 3. Introducing DB Browser for SQLite

SQLite is a lightweight, file-based relational database.
DB Browser is a graphical tool to manage SQLite databases easily.

🚀 Steps to Set Up:

  1. Download DB Browser for SQLite.

  2. Open the tool and click "New Database" to create a .sqlite file.

  3. Add tables manually:

    • Click "Create Table"

    • Define columns and set primary keys

    • Use Foreign Key to create relationships

🛠️ Activity:

Create the Customers and Orders tables using DB Browser:

  • CustomerID as PRIMARY KEY in Customers

  • CustomerID as FOREIGN KEY in Orders

📊 4. Basic SQL Queries

💡 What is an SQL Query?

SQL stands for Structured Query Language. It’s the standard language used to communicate with a database.
An SQL query is a command you write to ask the database to do something — such as retrieve, insert, update, or delete data.

Think of it like asking a question in a specific format:

  • “Show me all customers.”

  • “Find all orders made by customer 1.”

SQL helps you:

  • Access and view specific data

  • Combine data from multiple tables

  • Filter data using conditions

📌 Syntax:

👨‍💻 Examples:

  1. View all customers

  2. Get all orders for customer ID 1

💻 How to Run SQL Queries in DB Browser for SQLite:

  1. Open your database file in DB Browser.

  2. Go to the “Execute SQL” tab at the top.

  3. Type your SQL query in the text editor area.

  4. Click the “Play” button (▶) or press F5 to run the query.

  5. View your results in the “Data returned” section at the bottom.
